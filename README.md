# Rose Quartz Surprise

Create an extremely beautiful, immersive, interactive birthday website designed as a surprise birthday experience for someone special.

The website should feel like a premium romantic/aesthetic birthday experience, not like a basic birthday template. Make it feel carefully designed, emotional, magical, cute, elegant, and memorable.

🎀 OVERALL AESTHETIC

The main color palette should be centered around pink, with different shades used throughout:

Soft pastel pink

Baby pink

Blush pink

Rose pink

Hot pink as an accent

White / creamy white

Very subtle lavender accents if needed

Use beautiful gradients, soft glows, glassmorphism, subtle shadows, sparkles, and translucent elements.

The design should feel:
cute + elegant + dreamy + romantic + magical + luxurious + playful.

Avoid making it look childish or overly saturated. The pink should feel sophisticated and aesthetic.

Use beautiful typography:

An elegant script/cursive font for important headings

A clean modern font for normal text

Large expressive typography for emotional moments

Use plenty of whitespace and carefully balanced layouts.

✨ OPENING / LANDING SCREEN

Start with a beautiful full-screen animated opening.

The screen should initially be mostly minimal, with floating tiny pink particles, sparkles, hearts, and soft glowing effects slowly moving around.

Display a large animated message such as:

"Someone special has a birthday today... 💗"

Then underneath:

"And I made something just for you."

Have a beautiful glowing button:

"Open Your Surprise 💕"

When the button is clicked:

The entire screen should smoothly transition

Pink particles burst outward

Hearts float upward

A soft glow expands across the screen

The next section appears with a smooth cinematic transition

Add a subtle sound effect if audio is enabled

Do NOT make the transition instant.

💕 HERO SECTION

Create a stunning birthday hero section.

Large animated heading:

"Happy Birthday, [NAME]!"

Under it:

"Today is all about you. 💗"

Add animated floating hearts, sparkles, flowers, ribbons, stars, and tiny particles around the text.

The elements should move subtly rather than constantly distracting the user.

Add a beautiful birthday cake illustration or CSS-generated cake with:

Animated candles

Flickering flames

Soft glowing light

Small floating hearts

When the user interacts with the cake, the candles should react.

Include a button:

"There's More... ✨"

🌸 MEMORY / PHOTO SECTION

Create a beautiful interactive memory gallery.

Instead of a boring grid, make it feel like a digital scrapbook.

Include cards/photos with:

Rounded corners

Polaroid-style frames

Pink tape/sticker decorations

Small handwritten captions

Floating animations

Subtle rotations

Hover effects

Soft shadows

Photos should slightly tilt or move when hovered.

Clicking a photo should open a beautiful fullscreen/lightbox animation.

Add captions such as:

"One of my favorite memories 💗"

"This moment deserves its own place here."

Make the gallery responsive and visually impressive.

If no images are provided, use elegant placeholders that clearly indicate where photos can be inserted.

💌 LETTER SECTION

Create an interactive handwritten-style birthday letter.

The letter should appear inside a beautiful envelope.

Initially show:

"You have a letter 💌"

When clicked:

The envelope opens with a realistic animation

The letter slides upward

The background softly blurs

Tiny hearts appear around it

The letter should contain editable placeholder text:

"[WRITE YOUR PERSONAL BIRTHDAY MESSAGE HERE]"

Make the letter look like actual stationery with subtle paper texture, pink borders, little hearts, and elegant typography.

🎂 INTERACTIVE BIRTHDAY CAKE

Create a dedicated cake section.

Display a beautiful pink birthday cake with candles.

Allow the user to:

Click the candles

Blow them out if microphone interaction is supported

Watch the flames disappear

See a magical burst of sparkles

Display:

"Make a wish... ✨"

After the interaction, reveal:

"I hope every wish you make comes true. 💗"

Add confetti and floating hearts.

🎁 SURPRISE BOX

Create an interactive gift box.

The gift should gently bounce/pulse.

Text:

"I have one more surprise..."

When clicked:

The box opens

The lid physically rotates upward

Pink light shines out

Sparkles explode from inside

Confetti falls from the top

A hidden message/photo/card appears

Message:

"You deserve all the happiness in the world. 💗"

Make the animation feel satisfying and polished.

🌷 "THINGS I LOVE ABOUT YOU" SECTION

Create an interactive section containing several beautiful cards.

Example cards:

💗 Your smile
🌸 Your personality
✨ Your energy
🦋 The way you make people happy
🎀 Your kindness
🌙 The little things you do

Cards should animate into view as the user scrolls.

When hovering over a card:

It slightly lifts

The background changes

Tiny hearts/sparkles appear

The icon animates

Make all text editable.

📸 POLAROID MEMORY WALL

Create a section resembling a wall filled with scattered Polaroid photos.

Photos should have slightly different rotations.

Some should overlap.

Add handwritten-style notes such as:

"Remember this?"

"This one makes me smile."

"Never forget this day 💗"

When a photo is clicked, it should move forward and enlarge with a smooth animation.

💖 HEART ANIMATION

Throughout the website, have subtle animated hearts.

They should:

Float upward

Fade out

Have different sizes

Move at different speeds

Appear occasionally rather than constantly

Some sections should have tiny sparkles drifting through the background.

Make these animations performant and avoid overwhelming the page.

🌟 SCROLL ANIMATIONS

Scrolling should feel cinematic.

Use:

Fade-ins

Slide-ups

Scale animations

Parallax effects

Blur-to-focus transitions

Staggered animations

Floating objects

Smooth section transitions

Elements should animate naturally when they enter the viewport.

Do NOT animate everything simultaneously.

💗 FINAL BIRTHDAY MESSAGE

End the website with a spectacular final section.

Use a beautiful pink gradient background with glowing particles and floating hearts.

Display:

"Happy Birthday, [NAME] 💗"

Then:

"Thank you for being you."

And finally:

"Here's to another year of beautiful memories. ✨"

Add a large glowing heart.

When the user reaches this section:

Confetti should slowly begin falling

Hearts should float upward

Sparkles should appear

The background should gently glow

The text should have a subtle breathing animation

Add one final button:

"Replay the Surprise 💕"

Clicking it should smoothly return the user to the beginning.

🎵 MUSIC

Include optional background music.

Do NOT automatically force audio if browsers block autoplay.

Create a small elegant music button in the corner.

When music is playing:

Show a subtle animated music icon

Allow play/pause

Keep the control aesthetically integrated with the design

Use a placeholder audio file that can easily be replaced.

🖱️ MICRO-INTERACTIONS

Add lots of subtle premium interactions:

Buttons glow when hovered

Buttons slightly scale when clicked

Hearts appear when clicking certain elements

Cards tilt slightly toward the cursor

Cursor interactions create tiny sparkles

Images have smooth hover zoom

Text reveals itself elegantly

Decorative elements gently float

Buttons have soft ripple effects

Do not overdo these effects.

Everything should feel intentional and smooth.

🌙 OPTIONAL NIGHT MODE

Include a small toggle allowing the user to switch between:

Dreamy Pink Mode 🌸

and

Midnight Pink Mode 🌙

Midnight mode should use:

Dark pink

Burgundy

Deep purple

Black/pink gradients

Glowing pink particles

Make the transition between themes animated.

📱 RESPONSIVE DESIGN

The website MUST look excellent on:

Desktop

Laptop

Tablet

Mobile phones

On mobile:

Rearrange sections intelligently

Keep animations smooth

Make buttons easy to tap

Prevent horizontal scrolling

Ensure text remains readable

Resize images properly

Reduce extremely heavy animations if necessary for performance

🎨 VISUAL DETAILS

Add tasteful decorative elements throughout:

Hearts

Sparkles

Stars

Flowers

Ribbons

Bows

Tiny butterflies

Glitter

Soft clouds

Pink gradients

Glass cards

Elegant borders

Subtle grain/noise texture

Glowing blobs

Floating particles

Use these sparingly so the website remains elegant rather than cluttered.

🧠 IMPORTANT DESIGN PRINCIPLES

The website should feel like an experience, not a collection of random sections.

Every transition should connect naturally to the next section.

Use a consistent visual language.

Avoid generic Bootstrap-looking components.

Avoid plain rectangular buttons.

Avoid default browser styling.

Avoid excessive neon colors.

Avoid making everything pink with no variation.

Use depth, shadows, gradients, transparency, animation, spacing, and typography to create a premium appearance.

The final result should look like something that could realistically be presented as a professionally designed interactive birthday experience.

⚙️ TECHNICAL REQUIREMENTS

Build the entire website with clean, organized, maintainable code.

Use modern:

HTML

CSS

JavaScript

You may use lightweight libraries when they genuinely improve the experience, but avoid unnecessary dependencies.

Use CSS animations and JavaScript for interactive effects.

Use Intersection Observer for scroll-triggered animations where appropriate.

Ensure animations do not cause major performance issues.

Respect prefers-reduced-motion.

Keep all customizable information clearly marked, including:

Birthday person's name

Birthday message

Photos

Captions

Letter

Music

Favorite colors

Memories

Final message

Make these easy to modify.

💎 FINAL QUALITY REQUIREMENT

DO NOT create a basic birthday webpage.

Create something that makes the person feel like they have entered a personalized magical birthday world.

The first impression should immediately be:

"WAIT... YOU MADE THIS FOR ME?! 😭💗"

Prioritize visual beauty, smooth animation, emotional presentation, interaction, and attention to detail.

Every section should have a reason to exist.

The website should feel romantic, dreamy, cute, elegant, luxurious, interactive, and unforgettable.

Make the final implementation polished enough that it feels like a real premium website rather than an AI-generated template.
