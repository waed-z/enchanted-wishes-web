# Birthday Customization Studio

## Goal
Turn the birthday experience into a practical no-code builder with a separate recipient preview.

## Builder experience
- Add a dedicated “Customize Birthday” mode with clear tabs for basics, letters, photos and memories, sections, admiration notes, style, decorations, and music.
- Support adding, editing, removing, and reordering repeatable content with large touch-friendly controls.
- Let uploaded photos become cover images, letter attachments, gallery entries, and memory imagery, with captions and display styles.
- Add theme presets, custom color controls, decoration switches, cover-frame choices, music upload, playback, and volume.

## Birthday experience
- Drive every visible name, message, photo, memory, letter, card, color, decoration, and section order from the saved customization.
- Present multiple letters as animated envelopes and use uploaded photos across scrapbook, wall, carousel, and fullscreen views.
- Keep editor controls completely hidden in preview mode, with a discreet owner-only return path.

## Saving and preview
- Save structured content and uploaded media in the browser using IndexedDB so refreshes retain the project.
- Update the preview immediately while editing, with explicit Save, Preview, and Reset actions.
- Preserve a draft-versus-saved distinction so changes can be reviewed before sharing.

## Quality
- Match the existing romantic visual language rather than resembling an admin dashboard.
- Make the builder responsive, keyboard accessible, touch-friendly, and safe for reduced motion.
- Verify editing, uploads, saving, refreshing, preview separation, reordering, and reset on desktop and mobile.
